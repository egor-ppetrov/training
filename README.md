# «Форма» — мобильный PWA-план тренировок

Статическое приложение для GitHub Pages: план домашних тренировок с обычной длинной резинкой, техника упражнений, дневник питания (калории и БЖУ), замеры и напоминание на 11:00.

## Публикация на GitHub Pages

1. Создай на GitHub новый публичный репозиторий, например `forma`.
2. Загрузи **всё содержимое этой папки** в корень репозитория (`index.html`, `app.js`, `assets` и т.д.).
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main`, папку `/ (root)` и нажми Save.
6. Через 1–3 минуты GitHub покажет ссылку вида `https://твой-логин.github.io/forma/`.
7. Открой её на телефоне. В браузере выбери «Добавить на экран Домой» / Install app.

## Напоминания

GitHub Pages хранит только статические файлы — он не может самостоятельно отправлять фоновый push, когда телефон/браузер полностью закрыты.

- В приложении нажми на колокольчик и разреши уведомления: они работают, когда PWA открыто.
- Для **надёжного ежедневного** уведомления в 11:00 нажми «Скачать напоминание для календаря» и добавь `.ics` в календарь телефона. Это повторяющееся событие с уведомлением.

Если позднее нужен настоящий фоновый web-push, понадобится серверная часть/база подписок, например Firebase или Supabase + edge functions. Одного GitHub Pages для этого недостаточно.

## Данные

Дневник, отметки упражнений и замеры хранятся только в браузере телефона (`localStorage`). Не очищай данные сайта в браузере, иначе история удалится.

## Версия 2

- Карточка даты на главном экране открывает календарь: можно открыть план другого дня.
- Программа рассчитана на **маленькую замкнутую мини-резинку**. Она используется для ягодиц и стабилизации плеч. Для настоящих тяг спины позже понадобится длинная лента или тренажёры в зале.
- В питании есть режим «Порциями — на глаз». У каждого продукта есть средняя порция; её можно выбрать целой или дробной.
- После успешного разрешения уведомлений колокольчик скрывается.
